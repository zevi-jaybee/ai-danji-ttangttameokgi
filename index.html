01 · 설치와 연결

네 번에 나눠 설치합니다.
플러그인과 서버는 한 쌍입니다.

QGIS 안에 들어가는 플러그인과 Claude 쪽에서 도는 서버, 두 반쪽이 같은 번호여야 합니다. 이 매뉴얼은 플러그인 관리자가 주는 0.14.1 기준입니다(2026-09-17 공개). 예전 판(0.13)의 패널 [Start Server]는 이제 없고 툴바 아이콘 하나로 바뀌었습니다.

01

uv를 설치합니다

PowerShell을 열고 한 줄을 붙여 넣습니다. 프롬프트가 PS로 시작해야 PowerShell입니다. 설치가 끝나면 창을 닫고 새로 연 뒤 uv --version이 번호를 찍는지 봅니다. 창을 새로 열지 않으면 다음 단계에서 uvx를 못 찾습니다.

powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
02

QGIS 플러그인 QGIS MCP 0.14.1

플러그인 › 플러그인 관리 및 설치 › 검색창에 QGIS MCP. 저자 Nicolas Karasiak, 0.14.1을 설치합니다. 환영 창은 닫아도 됩니다. 플러그인 툴바에 아이콘이 하나 생기는데, 이것이 전부입니다.

아이콘을 누르면 서버가 켜지고 아이콘이 초록색이 됩니다. Claude가 붙으면 빨간 숫자가 달리고, 그 숫자가 연결된 클라이언트 수입니다. 아이콘 옆 ▾를 눌러 Auto-start on startup을 체크해 두십시오. 포트는 9876 그대로 둡니다.

03

Claude Code에 등록합니다

새 PowerShell 창에서 아래 한 줄을 실행합니다. 줄바꿈 없이 한 줄입니다. 주소 끝의 v0.14.1이 플러그인 관리자에서 설치한 번호와 같아야 합니다. -s user를 빼면 그 폴더에서만 등록되어 다른 폴더에서 claude를 켜면 QGIS가 안 보입니다.

claude mcp add -s user qgis -- uvx --from https://github.com/nkarasiak/qgis-mcp/archive/refs/tags/v0.14.1.zip qgis-mcp-server

▾ 메뉴의 Configure…를 열면 비슷한 명령을 만들어 주지만, 그 명령은 항상 최신판(main.zip)을 가리키고 -s user가 없습니다. 위 한 줄을 쓰십시오. Configure 창은 두 반쪽의 번호가 어긋났는지 확인하는 데 쓰면 됩니다. 어긋나면 주황 글씨로 알려 줍니다.

04

연결을 확인합니다

QGIS를 켜고 아이콘이 초록색인 상태에서 데이터 폴더로 이동해 Claude Code를 시작합니다. 처음 한 번은 서버 패키지 40개쯤을 내려받느라 몇 분 걸립니다.

cd "C:\studio3\내이름\buyeo_3km"
claude

세션이 열리면 두 문장

QGIS에 연결됐는지 ping 해 줘
diagnose 해서 플러그인 버전과 서버 버전이 같은지 봐 줘

pong이 오고 plugin 0.14.1 / server 0.14.1처럼 두 숫자가 같으면 끝입니다. mismatch가 나오면 03의 주소 끝 번호를 플러그인 번호에 맞추고, PowerShell에서 uv cache clean qgis-mcp를 실행한 뒤 Claude Code를 다시 시작합니다.

처음 몇 번은 Claude Code가 도구를 써도 되는지 묻습니다. ping·diagnose·get_으로 시작하는 읽기 도구는 "항상 허용"으로 두어도 됩니다. execute_code·remove_layer·delete_features는 매번 확인하십시오. 여러분 QGIS 안에서 파이썬이 그대로 실행되는 도구입니다.

왜 번호를 맞추나. 어긋나도 기본 기능은 됩니다. 다만 최근에 추가된 도구만 "알 수 없는 명령"으로 조용히 실패해서 원인을 찾기가 아주 어렵습니다. 이번 학기 안에도 판이 바뀔 수 있으니, 플러그인을 올렸다면 서버 번호도 같이 올리십시오.

02 · 작업 규칙

편해지는 만큼 위험해집니다.
다섯 가지만 지키십시오.

Claude가 만든 파이썬 코드는 여러분 QGIS의 권한으로 그대로 실행됩니다. 빨라진 만큼, 무엇이 실행되는지 아는 사람만 안전합니다.

01

원본은 두고 사본에서

zip을 두 번 풀어 하나는 buyeo_3km_원본으로 이름을 바꿔 두십시오. gpkg가 덮어써질 수 있습니다. 제가 다시 드릴 수는 있지만 여러분이 그 위에 얹은 작업은 못 살립니다.

02

멈춘 것처럼 보여도 1분

명령이 도는 동안 QGIS 전체가 얼어붙습니다. 55초가 지나면 도구가 스스로 끊고 그때까지의 출력을 돌려줍니다. 강제 종료하면 작업물이 날아갑니다.

03

QGIS가 죽으면 원인은 대개 하나

화면이 그려지는 중에 같은 레이어를 편집하면 access violation으로 죽습니다. 다시 켜고 마지막 문장을 다시 시키되 "편집 전에 캔버스를 멈추고(freeze) 끝나면 풀어"를 붙이십시오. 이 매뉴얼을 만들며 두 번 겪었습니다.

04

작업 단위가 끝나면 /clear

QGIS 도구가 118개 붙어 있어 대화가 길어지면 토큰이 빨리 찹니다. 도로를 끝냈으면 한 번, 가구를 끝냈으면 또 한 번 비웁니다.

05

I

작업 파일을 만듭니다

배포 gpkg는 손대지 않습니다. 같은 폴더에 계획용 gpkg를 따로 만들고 다섯 레이어를 빈 채로 넣습니다. 좌표계는 배포본과 같은 EPSG:5179, 면적은 나중에 5186에서 잽니다.

QGIS에서 프로젝트 폴더에 plan_v1.gpkg를 만들고 EPSG:5179로 다섯 레이어를 빈 채로 넣어 줘. 01_도로중심선(선: 위계·노선 문자, 폭원 실수), 02_도로면(면: 용도, 면적), 03_가구(면: 가구·용도 문자, 면적·장변·단변 실수, 획지수 정수), 04_획지(면: 번호·획지유형·가구 문자, 면적·전면폭·깊이·세장비·접도연장 실수, 맹지 불리언), 05_용지(면: 용지, 면적). 그룹 'A1 계획'으로 올려 줘

도구 execute_code(QgsVectorFileWriter) → create_layer_group · add_vector_layer

확인: 레이어 패널에 그룹과 다섯 레이어가 보이고, 각 레이어의 좌표계가 EPSG:5179인지 "다섯 레이어의 좌표계와 필드를 표로 보여 줘"로 되묻습니다.

왜 gpkg 하나에 다섯 레이어인가. SHP는 필드명이 10바이트에서 잘리고 한글이 깨집니다. gpkg는 한 파일에 여러 레이어를 담고 UTF-8이라 편입면적_㎡ 같은 이름도 그대로 갑니다. 판을 바꿀 때는 파일째 복사해 plan_v2.gpkg로 씁니다.
II

도로중심선을 긋습니다

길은 선 하나에 폭원 숫자를 붙여 그립니다. 도로면은 다음 단계에서 Claude가 폭원으로 부풀립니다. 그래서 여기서는 위계와 폭원을 정하는 것이 일이고, 선을 예쁘게 긋는 것은 일이 아닙니다.

두 가지 방법이 있습니다. 하나는 QGIS에서 마우스로 긋는 것(편집 모드 → 선 객체 추가, 스냅 켜기)이고, 다른 하나는 좌표나 관계를 말로 주는 것입니다. 데모는 뒤쪽입니다. A1은 서쪽 변이 대로1류(259 m), 북쪽 변이 중로2류(241 m), 동쪽 변이 소로2류(137 m)라 진입은 북쪽에서 받고 서쪽은 차량 출입을 막습니다.

01_도로중심선에 선 일곱 개를 넣어 줘. R1 어귀길 8m: 북쪽 경계 x=946690에서 남쪽 A2 경계까지 남북. R2 안길 8m: y=1808400에서 서쪽 경계부터 동쪽 경계까지 동서. R3·R4 샛길 6m: y=1808465, 1808350 동서. R5 샛길 6m: x=946770, R3에서 R4까지. R6 골목 4m: x=946632, R3에서 R4까지. R7 골목 4m: y=1808312, 서쪽 경계에서 R1까지. 다 넣은 뒤 01_부지경계 A1으로 잘라내고, 노선별 연장을 EPSG:5186에서 재서 표로 보여 줘

도구 add_features(WKT) → execute_code(부지로 자르기, 연장)

III

도로면과 완충녹지를 만듭니다

중심선을 폭원의 절반으로 양쪽에 부풀리면 도로면이 됩니다. 끝을 둥글리지 말고 평탄하게(flat) 잘라야 교차부가 깨끗합니다. 대로1류에 면한 서쪽 변은 안쪽으로 10 m 완충녹지를 두고, 도로가 녹지를 관통하지 않게 뺍니다.

01_도로중심선을 각 노선의 폭원/2로 평탄 끝(flat cap) 버퍼해서 하나로 합치고 A1으로 잘라 02_도로면에 넣어 줘. 04_도시계획도로의 대로1류에 면한 A1 변에서 안쪽 10 m를 완충녹지로 만들어 05_용지에 '완충녹지'로 넣고, 도로면에서는 그 녹지를 빼 줘. 둘 다 면적은 EPSG:5186으로. 폭원×연장 합과 도로면 실측 면적도 같이 보여 줘

도구 execute_code(buffer · unaryUnion · difference) — 또는 execute_processing native:buffer + native:dissolve + native:clip

AutoCAD에서 안 열리면

ezdxf로 한 번 다시 저장

QGIS가 쓴 DXF는 코드페이지가 비어 있어 AutoCAD가 "Invalid or incomplete DXF input"으로 거부하거나 한글 레이어명이 깨질 수 있습니다. "ezdxf로 읽어 인코딩 cp949, $DWGCODEPAGE ANSI_949로 다시 저장해 줘". 그렇게 만든 파일을 AutoCAD 2026에서 열어 AUDIT 오류 0, 획지 105개를 확인했습니다.

배포 qgz는 두고 다른 이름으로
